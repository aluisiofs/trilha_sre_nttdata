# Trilha SRE Júnior (v11) - NTT DATA
Repositório de documentação, automações e projetos da Trilha de Formação em Engenharia de Confiabilidade de Sistemas (SRE).

## Estrutura do Repositório
- `docs/`: Documentos de governança, arquitetura, SLI/SLO e pós-mortems.
- `src/`: Códigos de automação e instrumentação de serviços.
- `config/`: Configurações de monitoramento (Prometheus, Grafana, etc.).
- `scripts/`: Scripts utilitários para mitigação e testes de carga.
